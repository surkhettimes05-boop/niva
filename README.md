# NIVA — Coming Soon

A responsive, static launch page for NIVA, an accessible-premium personal-care brand.

## Deploy
This repository is a static site. Deploy the root directory on Vercel, Netlify, GitHub Pages, or another static host. No build command is required.

## Identity direction in this page
- Ink navy `#101F3B`
- Flare orange `#FF6538`
- Warm paper `#F5F0E8`
- Fresh blue `#92D4E8`
- Typography: Space Grotesk + DM Sans
- Responsive, CSS-only product-packaging illustration

The illustrated pack is a visual teaser, not production packaging artwork.
